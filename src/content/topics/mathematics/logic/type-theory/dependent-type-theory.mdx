**Dependent Type Theory.** Martin-Löf type theory and Calculus of Inductive Constructions.

## Foundations and canonical references

The standard treatments of dependent type theory approach the subject from complementary angles. Nederpelt, *Type Theory and Formal Proof* (2014) is the anchor reference for the subject and lays out the core definitions, theorems, and worked examples that practitioners return to.

Open methodological questions for dependent type theory include sharpening the bridges between foundational theory and computational practice, extending classical results to broader or more structured settings, and integrating the techniques surveyed above with adjacent mathematical disciplines. The references listed in this page are the entry points that current work builds on.
