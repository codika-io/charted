**Axiomatic Set Theory.** ZFC, NBG, and Morse–Kelley axiomatizations.

## Foundations and canonical references

The standard treatments of axiomatic set theory approach the subject from complementary angles. Jech, *Set Theory* (2003) is the anchor reference for the subject and lays out the core definitions, theorems, and worked examples that practitioners return to. Kunen, *Set Theory: An Introduction to Independence Proofs* (1980) gives a parallel, more proof-oriented exposition of the same material and is widely used as a graduate text.

Open methodological questions for axiomatic set theory include sharpening the bridges between foundational theory and computational practice, extending classical results to broader or more structured settings, and integrating the techniques surveyed above with adjacent mathematical disciplines. The references listed in this page are the entry points that current work builds on.
