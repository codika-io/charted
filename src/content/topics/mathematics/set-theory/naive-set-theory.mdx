**Naive Set Theory.** Sets, relations, functions, and Cantor's paradoxes. This page collects canonical references that organise the subject and provide entry points to its main techniques.

## Foundations and canonical references

The standard treatments of naive set theory approach the subject from complementary angles. Halmos, *Naive Set Theory* (1974) is the anchor reference for the subject and lays out the core definitions, theorems, and worked examples that practitioners return to.

Open methodological questions for naive set theory include sharpening the bridges between foundational theory and computational practice, extending classical results to broader or more structured settings, and integrating the techniques surveyed above with adjacent mathematical disciplines. The references listed in this page are the entry points that current work builds on.
