**Advanced Set Theory.** Constructible universe, inner models, and combinatorial set theory.

## Foundations and canonical references

The standard treatments of advanced set theory approach the subject from complementary angles. Kanamori, *The Higher Infinite* (2003) is the anchor reference for the subject and lays out the core definitions, theorems, and worked examples that practitioners return to.

Open methodological questions for advanced set theory include sharpening the bridges between foundational theory and computational practice, extending classical results to broader or more structured settings, and integrating the techniques surveyed above with adjacent mathematical disciplines. The references listed in this page are the entry points that current work builds on.
