**Functional Data Analysis.** Statistics for curves and surfaces as data objects.

## Foundations and canonical references

The standard treatments of functional data analysis approach the subject from complementary angles. Ramsay, *Functional Data Analysis* (2005) is the anchor reference for the subject and lays out the core definitions, theorems, and worked examples that practitioners return to.

Open methodological questions for functional data analysis include sharpening the bridges between foundational theory and computational practice, extending classical results to broader or more structured settings, and integrating the techniques surveyed above with adjacent mathematical disciplines. The references listed in this page are the entry points that current work builds on.
